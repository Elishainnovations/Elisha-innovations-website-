
ELISHA INNOVATION BOARDING HOUSE WEBSITE

Files:
- index.html = public advertising website
- admin.html = page for adding/removing listings
- advert.png = supplied advertising artwork

How to use:
1. Upload all files to a web host.
2. Open index.html for the public website.
3. Open admin.html to add listings.

Important:
This starter admin page stores posts in the browser's local storage. That means posts are not automatically shared across different phones/devices. For a true public posting system, the site needs an online database and authenticated admin login.
